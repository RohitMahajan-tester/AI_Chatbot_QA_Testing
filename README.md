# AI Customer Support Chatbot - Manual QA Testing

An independent QA portfolio project demonstrating manual testing of an AI customer-support chatbot.

## Scope

- Functional Testing
- UI Testing
- Negative Testing
- AI-specific Functional Testing
- API Testing with Postman
- Defect Reporting
- Test Execution and Reporting

## Important

This is an independent portfolio project. It does not contain any employer,
client, proprietary application, credentials, or confidential information.

The chatbot application is a local demo created specifically for testing.
